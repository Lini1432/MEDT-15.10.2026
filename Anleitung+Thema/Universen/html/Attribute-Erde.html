Erde – Attribute

Attribute geben HTML-Elementen zusätzliche Informationen. Sie stehen immer im Start-Tag und bestehen aus einem Namen und einem dazugehörigen Wert.

Zum Beispiel wird bei einem Bild mit src festgelegt, welches Bild angezeigt werden soll. Bei einem Link gibt href an, wohin der Link führt.

Einige häufig verwendete Attribute sind:

  • src - Quelle, zum Beispiel bei Bildern
  • href - Ziel eines Links
  • alt - Alternativtext für ein Bild
  • width - Breite
  • height - Höhe
  • title - zusätzliche Information

Attribute helfen dabei, HTML-Elemente genauer zu beschreiben und ihr Verhalten festzulegen.
