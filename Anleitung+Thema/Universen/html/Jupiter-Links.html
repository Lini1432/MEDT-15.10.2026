Jupiter – Bilder & Links

Mit HTML können Bilder und Links in eine Webseite eingebunden werden.

Für Bilder wird das <img>-Element verwendet. Mit src wird angegeben, welches Bild angezeigt werden soll. Mit alt kann ein Alternativtext für das Bild festgelegt werden.

Mit dem <a>-Element können Links erstellt werden. Das Attribut href bestimmt, wohin der Link führt.

Auch ein Bild kann als Link verwendet werden. Dafür wird das <img>-Element innerhalb eines <a>-Elements platziert.
