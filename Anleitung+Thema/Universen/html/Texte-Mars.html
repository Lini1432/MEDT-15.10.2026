Mars - Texte & Überschriften

Mit HTML können Texte und Überschriften auf einer Webseite strukturiert und hervorgehoben werden.

Für Überschriften gibt es die Tags <h1> bis <h6>. Dabei ist <h1> die wichtigste Überschrift. <h6> ist die niedrigste Überschriftenebene.

Für normale Textabsätze wird das <p> -Element verwendet. Mit <br> kann ein Zeilenumbruch eingefügt werden.

Mit <strong> können besonders wichtige Textstellen hervorgehoben werden. Der Inhalt wird dabei vom Browser normalerweise fett dargestellt.

Durch verschiedene Überschriften, Absätze und Hervorhebungen kann der Inhalt einer Webseite übersichtlich gegliedert werden.
