Merkur – Grundlagen von HTML

HTML steht für HyperText Markup Language und ist die grundlegende Auszeichnungssprache des Webs. Mit HTML wird die Struktur einer Webseite festgelegt.

HTML ist keine Programmiersprache, sondern eine Markup Language. Es wird verwendet, um Inhalte wie Texte, Überschriften, Bilder und Links auf einer Webseite zu strukturieren.

Eine HTML-Seite besteht aus verschiedenen Elementen. Diese werden mit sogenannten Tags geschrieben. Die Tags zeigen dem Browser, um welche Art von Inhalt es sich handelt.

Eine einfache HTML-Seite besitzt eine grundlegende Struktur mit <html>, <head> und <body>. Im <head> befinden sich Informationen über die Webseite, während im der sichtbare Inhalt steht.

HTML bildet damit die Grundlage jeder Webseite.
