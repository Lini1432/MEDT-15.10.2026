Sonne – HTML

HTML steht für HyperText Markup Language und ist die grundlegende Auszeichnungssprache des Webs. Mit HTML wird die Struktur einer Webseite festgelegt. Es bestimmt, welche Inhalte auf einer Seite vorhanden sind und wie diese gegliedert werden.

HTML ist keine Programmiersprache, sondern eine Markup Language. Mit verschiedenen Elementen und Tags können zum Beispiel Überschriften, Texte, Bilder, Links, Listen und Tabellen in eine Webseite eingebunden werden.

Eine HTML-Seite besitzt eine grundlegende Struktur. Dazu gehören unter anderem <html>, <head> und <body>. Im <head> befinden sich Informationen über die Webseite, während der sichtbare Inhalt im <body> steht.

Auch Attribute spielen eine wichtige Rolle. Sie geben HTML-Elementen zusätzliche Informationen und können beispielsweise festlegen, welches Bild angezeigt wird oder wohin ein Link führt.

Die einzelnen Planeten unserer HTML-Galaxie stellen die verschiedenen Bereiche dar, die wir kennengelernt haben. Die Sonne bildet dabei den Mittelpunkt und verbindet alle diese Themen miteinander.

HTML ist damit die Grundlage unserer gesamten Webseite und bildet das Zentrum unserer Milchstraßen-Galaxie.
