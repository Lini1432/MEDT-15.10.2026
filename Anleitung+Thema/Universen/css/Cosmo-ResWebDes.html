Cosmo – Responsive Web Design

Responsive Web Design bedeutet, dass sich eine Webseite an unterschiedliche Bildschirmgrößen und Geräte anpassen kann.

Das ist besonders wichtig, weil Webseiten nicht nur auf großen Computermonitoren, sondern auch auf Tablets und Smartphones angezeigt werden. Mit CSS können Regeln erstellt werden, die abhängig von bestimmten Eigenschaften des Geräts angewendet werden.

Dafür werden sogenannte Media Queries verwendet. Sie können zum Beispiel prüfen, wie viel Platz auf einem Bildschirm zur Verfügung steht, und anschließend eine passende Gestaltung anwenden.
