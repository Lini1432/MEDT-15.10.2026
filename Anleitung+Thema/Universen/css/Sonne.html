Sonne-CSS

CSS steht für Cascading Style Sheets und wird verwendet, um das Aussehen und die Gestaltung einer Webseite festzulegen. Mit CSS wird bestimmt, wie die Inhalte einer Webseite dargestellt werden und wie die einzelnen Elemente gestaltet sind.

CSS ist keine Programmiersprache, sondern eine Stylesheet-Sprache. Mit verschiedenen Eigenschaften und Werten können zum Beispiel Farben, Schriftarten, Größen, Abstände und Hintergründe einer Webseite festgelegt werden.

CSS besteht aus Regeln, die festlegen, welche HTML-Elemente gestaltet werden und wie diese aussehen sollen. Dabei bestimmen Selektoren, auf welche Elemente eine Regel angewendet wird, während Eigenschaften und Werte die Gestaltung festlegen.

Auch das Box Model spielt eine wichtige Rolle. Es beschreibt den Aufbau eines HTML-Elements und besteht aus dem Inhalt, dem Innenabstand (Padding), dem Rahmen (Border) und dem Außenabstand (Margin).

Die einzelnen Planeten unserer CSS-Galaxie stellen die verschiedenen Bereiche dar, die wir kennengelernt haben. Die Sonne bildet dabei den Mittelpunkt und verbindet alle diese Themen miteinander.

CSS ist damit die Grundlage für die Gestaltung unserer Webseite und bildet das Zentrum unserer Andromeda-Galaxie.
