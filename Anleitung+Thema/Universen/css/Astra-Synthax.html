Astra – CSS-Grundlagen & Syntax

CSS steht für „Cascading Style Sheets“ und wird verwendet, um das Aussehen und die Gestaltung von Webseiten festzulegen. Mit CSS können zum Beispiel Farben, Schriftarten, Größen und Abstände verändert werden.

Eine CSS-Datei besteht aus CSS-Regeln. Jede Regel besteht aus einem Selektor und Deklarationen. Der Selektor bestimmt, welche HTML-Elemente gestaltet werden sollen. Die Deklarationen legen fest, wie diese Elemente aussehen sollen.

CSS trennt die Gestaltung von der eigentlichen Struktur einer Webseite. Dadurch kann das gleiche Design für mehrere Seiten verwendet werden.
