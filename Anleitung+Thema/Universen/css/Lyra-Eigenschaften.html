Lyra – CSS-Eigenschaften & Formatierung

Mit CSS können viele Eigenschaften von HTML-Elementen verändert werden. Dazu gehören zum Beispiel Farben, Hintergründe, Schriftarten, Schriftgrößen und Textausrichtung.

Auch Listen, Tabellen und Links können mit CSS gestaltet werden. Manche Eigenschaften werden automatisch von einem übergeordneten Element an untergeordnete Elemente weitergegeben. Dazu gehören beispielsweise bestimmte Farben und Schriftarten.

Andere Eigenschaften wie Rahmen oder Abstände werden normalerweise nicht vererbt.
