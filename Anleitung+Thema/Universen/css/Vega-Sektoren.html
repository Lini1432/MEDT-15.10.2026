Vega – Selektoren

Selektoren bestimmen, auf welche HTML-Elemente eine CSS-Regel angewendet wird. Es gibt verschiedene Arten von Selektoren.

Mit einem Element-Selektor können bestimmte HTML-Tags ausgewählt werden. ID-Selektoren sprechen ein bestimmtes Element über seine ID an, während Klassen-Selektoren mehrere Elemente mit derselben Klasse gestalten können.

Zusätzlich gibt es unter anderem Universal- und Attributselektoren. Auch Zustände von Elementen können mit sogenannten Pseudo-Klassen angesprochen werden, zum Beispiel wenn sich die Maus über einem Element befindet.
