Nova – Einbindung von CSS in HTML

CSS kann auf verschiedene Arten mit HTML verbunden werden. Es gibt drei grundlegende Möglichkeiten: Inline-CSS, interne Stylesheets und externe Stylesheets.

Bei Inline-CSS wird die Gestaltung direkt bei einem HTML-Element angegeben. Bei einem internen Stylesheet befinden sich die CSS-Regeln im HTML-Dokument. Bei einem externen Stylesheet werden die CSS-Regeln in einer eigenen .css-Datei gespeichert.

Externe Stylesheets sind besonders praktisch, weil eine CSS-Datei für mehrere HTML-Seiten verwendet werden kann.
