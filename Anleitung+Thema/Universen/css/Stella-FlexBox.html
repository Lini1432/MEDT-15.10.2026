Stella – Display & Flexbox

Mit der CSS-Eigenschaft display kann festgelegt werden, wie sich ein Element auf einer Webseite verhält. Wichtige Werte sind none, inline, block und inline-block.

Flexbox ermöglicht es, Elemente innerhalb eines Containers flexibel anzuordnen. Mit display: flex wird ein Element zu einem Flex-Container.

Mit Eigenschaften wie flex-direction, justify-content und align-items können Richtung und Ausrichtung der Elemente bestimmt werden. Dadurch lassen sich beispielsweise Inhalte nebeneinander oder untereinander anordnen.
