Luna – Cascade, Spezifität & Vererbung

Bei CSS kann es vorkommen, dass mehrere Regeln auf dasselbe HTML-Element angewendet werden. Die sogenannte Cascade bestimmt dann, welche Regel verwendet wird.

Dabei spielen unter anderem die Wichtigkeit, die Spezifität und die Reihenfolge der Regeln eine Rolle. Spezifität beschreibt, wie genau ein Selektor ein Element anspricht. Ein spezifischerer Selektor hat dabei eine höhere Priorität.

Vererbung bedeutet, dass bestimmte CSS-Eigenschaften von einem übergeordneten Element an seine untergeordneten Elemente weitergegeben werden können. Dadurch können beispielsweise Schriftarten oder Farben für mehrere Elemente gleichzeitig festgelegt werden.
