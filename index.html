Willkommen auf einer Reise durch die Welt von HTML und CSS.

Im Zentrum unseres Universums befinden sich zwei Galaxien:

HTML – unsere Galaxie

HTML bildet die Grundstruktur einer Webseite. In dieser Galaxie befinden sich verschiedene Planeten, die für die einzelnen HTML-Themen stehen.

CSS-Andromeda

CSS kümmert sich um die Gestaltung einer Webseite. Auch diese Galaxie besteht aus verschiedenen Planeten, auf denen die unterschiedlichen CSS-Themen zu finden sind.
